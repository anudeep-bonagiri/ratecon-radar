    How this works

    1. Your PDF is read in the browser. pdf.js pulls the text out. The file never leaves this tab.
    2. Gemma reads each sentence. An open-weight Google Gemma model runs on your own GPU through WebGPU and Transformers.js. It labels each clause and writes one plain line about what it means for you.
    3. Every flag shows its source. The quoted text is taken straight from the document, so you can check the model's reading.
    Tries to send a request to an outside server from this page and from the model's worker. The browser should refuse both.

    RateCon Radar is a reading aid, not legal advice. It can miss clauses and it can misread them. Read the document yourself before you sign. Source code and test results: github.com/anudeep-bonagiri/ratecon-radar.
